# Logo source

`mi-logo-white.png` is the unmodified embedded white-on-black primary long logo (image object 14, page 3) from the Morris Interactive Brand Guidelines supplied for this project. It is not recreated, recoloured or stretched. Original proportions and generous clear space are preserved. Visby font files were not supplied or extracted; the interface uses a system sans-serif fallback without external font requests. These brand assets remain Morris Interactive property.
